Singly Linked List
각 노드: element + next 포인터 | head에서 시작, 마지막 next = null
head
tail

Doubly Linked List
각 노드: prev + element + next | header/trailer dummy node 사용 | 양방향 이동 가능
dummy (header/trailer)
새로 삽입
값을 입력하고 삽입해봐
Stack as Linked List
top = head | push → head에 삽입 | pop → head에서 삭제 | 모두 O(1)
push로 쌓고 pop으로 꺼내봐 (LIFO)
Queue as Linked List
front = head (dequeue쪽) | rear = tail (enqueue쪽) | 모두 O(1)
front (dequeue)
rear (enqueue)
enqueue로 넣고 dequeue로 꺼내봐 (FIFO)
